# Live SEO guardian reports

Generated by `automation/scripts/seo-live-audit.mjs`, committed by
`.github/workflows/seo-monitor.yml` on each run (every 6h):

- `latest.json` — full structured result (per-page issues + summary + errorKeys)
- `latest.md`   — human-readable summary (errors first)
- `history.csv` — one row per run: when, score, pages, errors, warns, infos

The guardian alerts (Slack + email) **only on new errors** vs the previous
run — it's a regression watchdog, not a nag. These files are runtime
artifacts; the first scheduled run creates them.
